# NOVA TERRA

开普勒-442 轨道殖民地 · 公元 2487。一个可以自由飞行浏览的 three.js 场景，整个页面就是一个 `index.html`。

## 运行

```bash
python3 -m http.server   # 然后打开 http://localhost:8000
```

页面会先找同目录的 `three.module.min.js`，找不到就依次从 npmmirror、jsDelivr、unpkg、cdnjs 加载 three.js 0.160.0。

## 操作

拖拽环顾，W A S D 飞行，Q / E 升降，Shift 加速，滚轮变焦，C 自动巡航，L 宽银幕，H 隐藏文字。
